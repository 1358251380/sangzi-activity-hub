## A. Git for Windows

### 步骤

1. 打开 https://git-scm.com/download/win
2. 下载 **64-bit Git for Windows Setup**
3. 运行安装包，全部保持默认即可（默认已包含：加入 PATH、Git Bash、OpenSSL）
4. 安装完成后**关闭所有终端窗口**（PATH 需要新进程才生效）

### 验证（新开 PowerShell 执行）

```powershell
git --version
```

期望输出类似 `git version 2.47.1.windows.1`。

### 首次配置（只需一次）

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git config --global core.autocrlf true
```

> `core.autocrlf true` 在 Windows 上很重要，能避免换行符导致的整文件 diff 噪音。

## B. Docker Desktop

### 前置条件检查

先在管理员 PowerShell 里确认 WSL2 状态：

```powershell
wsl --status
```

- 如果提示 **WSL 未安装** → 先执行 `wsl --install`，然后**重启电脑**
- 如果已安装但版本旧 → 执行 `wsl --update`
- 如果报 **虚拟化未启用** → 需进 BIOS 打开 `Intel VT-x` / `AMD-V`（SVM）

### 步骤

1. 打开 https://www.docker.com/products/docker-desktop/
2. 下载 **Docker Desktop for Windows (AMD64)**
3. 运行安装包，勾选 **Use WSL 2 instead of Hyper-V (recommended)**
4. 安装完成后**重启电脑**
5. 首次启动 Docker Desktop，接受服务协议，跳过登录（可选）
6. 等待左下角状态变为 **Engine running**

### 验证

```powershell
docker --version
docker compose version
docker run --rm hello-world
```

期望：显示版本号，且 `hello-world` 打印 `Hello from Docker!`。

### 注意事项

- **Docker Desktop 必须保持运行**，否则 `docker` 命令会报 `cannot connect to the Docker daemon`
- 建议在设置里勾选 `Start Docker Desktop when you sign in`，开机自启
- 首次拉取镜像需要网络，国内网络慢的话可在 `Docker Desktop → Settings → Docker Engine` 里配置镜像加速地址
